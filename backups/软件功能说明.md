# 可靠性测试报告自动化工具 - 功能说明

## 二、核心功能

### 1. 报告编辑功能

#### 1.1 多模板支持
- 通用模板：适用于常规可靠性测试报告
- 通用（英文）模板：国际化报告支持（待开发）
- 华为模板：定制化客户报告（待开发）

#### 1.2 智能编辑
- **可编辑区域**：蓝色标识的字段可自由编辑，支持文本内容修改
- **固定内容**：黑色文字为模板固定内容，在报告编辑中不可修改
- **格式工具栏**：支持字体、字号、颜色、加粗、斜体、下划线、对齐等格式设置
- **批量操作**：Ctrl + 点击多选文本框，一次性修改多个区域的格式
- **自适应布局**：区域高度根据内容自动调整，支持手动调整

#### 1.3 动态内容管理
- **测试结果信息区域**：默认3行，支持动态增删
- **测试图片区域**：默认3行，每行3个方框（测试前、测试中、测试后）
- **行操作功能**：
  - 末尾添加行：批量在末尾添加指定数量的行
  - 指定位置插入行：在指定位置精确插入行
  - 末尾删除行：批量从末尾删除指定数量的行
  - 指定位置删除行：删除指定位置的行
  - 安全机制：所有删除操作需用户确认，至少保留一行

#### 1.4 图片管理
- **多种上传方式**：点击上传、拖拽上传、文件夹批量上传
- **智能布局**：根据图片数量和尺寸自动调整布局，等比例缩放填充方框
- **拖拽排序**：支持拖拽调整图片顺序
- **自适应显示**：图片自动适配方框尺寸，保持等比例

#### 1.5 草稿管理
- **保存草稿**：为当前编辑内容命名并保存
- **打开草稿**：从草稿列表中选择加载
- **删除草稿**：安全删除不需要的草稿
- **自动保存**：编辑内容自动保存，防止数据丢失

### 2. 模板编辑功能

#### 2.1 模板定制
- **固定内容编辑**：修改报告中的固定文本内容
- **可编辑区域设置**：定义报告编辑界面中的可编辑字段及其提示文本
- **样式设置**：支持字体、字号、颜色、对齐等样式定制
- **批量格式化**：Shift + 拖拽框选多个区域，批量修改格式

#### 2.2 图片元素管理
- **Logo 上传**：左上角公司 Logo，支持大小和位置调整
- **电子签名**：测试员、审核、核准的电子签名图片上传
- **部门章**：透明背景部门章，支持自由拖拽和大小调整
- **固定长宽比**：所有图片调整保持原始比例

#### 2.3 模板应用机制
- **隔离编辑**：模板修改不会自动同步到报告编辑
- **手动应用**：点击"应用于报告编辑"按钮后才生效
- **模板导入导出**：支持 JSON 格式的模板配置分享

### 3. PDF 导出功能

#### 3.1 导出特性
- **所见即所得**：导出的 PDF 与网页显示完全一致
- **自动分页**：根据内容自动计算分页，确保格式规范
- **页眉页脚**：每页自动添加公司名称和备注信息
- **跨页处理**：内容跨页时自动添加区域标题
- **部门章显示**：编辑时可隐藏，导出时正常显示

#### 3.2 页面规范
- **A4 尺寸**：标准 A4 页面尺寸（210mm × 297mm）
- **统一布局**：所有页面保持一致的页眉、页脚和边距
- **密级标识**：支持绝密、机密、内部公开、外部公开四种密级选择

### 4. 其他功能

#### 4.1 更新日志
- 版本历史记录查看
- 详细更新内容展示
- 版本间功能对比

#### 4.2 关于页面
- 工具使用说明
- 版本信息展示
- 开发人员信息
- 技术支持联系方式

## 三、技术特点

### 3.1 离线运行
- 本地部署，无需网络连接
- 数据完全本地存储，保护隐私安全
- 打包发布后可独立运行

### 3.2 技术架构
- **后端**：Flask（Python）
- **前端**：Vue.js 3 + Element Plus
- **PDF 生成**：html2canvas + jsPDF（客户端生成）
- **数据存储**：本地 JSON 文件

### 3.3 用户体验
- 现代化 UI 设计，界面美观
- 响应式布局，操作流畅
- 粘性工具栏，便捷操作
- 实时预览，所见即所得

## 四、应用场景

1. **可靠性测试报告生成**：规范化输出测试结果
2. **多模板管理**：适配不同客户和场景需求
3. **团队协作**：模板导入导出，统一报告格式
4. **历史记录管理**：草稿保存，随时恢复编辑
5. **快速迭代**：批量操作，提高编辑效率
